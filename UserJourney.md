I want to build a AI shopping assistant for crystal shopping.

This document explains the user journey for the AI shopping assistant. 

Shopping Assistant Profile page:
1. User should be able to view the Shopping Assistant Profile page.
- All the Shopping Assistant Profile information should be configurable in the admin panel. 
2. User should be able to view the Flash Deals and Weekly Picks in the Shopping Assistant Profile page.
- All the Flash Deals and Weekly Picks information should be configurable in the admin panel. 
3. User should be able to click the "Click to Chat" button to start chatting with the AI shopping assistant.
4. User should be able to ask anything questions about the products in the Shopping Assistant Profile page.
- User should be able to ask anything questions about the products in the Flash Deals and Weekly Picks.

Chat interface:
1. User should be able to chat with the AI shopping assistant in natural language. 
2. In the chat interface, the AI shopping assistant should be able to display product cards based on the current conversation. 
- The AI shopping assistant should carry on the conversation naturally, and display product cards only when necessary. 


Product Listing page:
1. User should be able to view the products in the Product Listing page. 
2. In the Product Listing page, user should be able to filter the products by predefined filters.
- the primary filters should be: 按颜色材质 / 按款式风格 / 按手串类型. These are the parent categories. The default selected filter should be the parent category "按颜色材质".
- The secondary filters should be the subcategories of the parent category. 
- When the user selects 按颜色材质, the secondary filters contains 2 rows, one for the color and one for the material.
- When the user selects 按款式风格, the secondary filter contains 1 row, which is category_name.
- When the user selects 按手串类型, the secondary filter contains 1 row, which is category_name.
- User should be able to select multiple subcategories in the secondary filters.
- User should be able to select price range. 

3. In the Product Listing page, user should be able to filter the products by natural language.
4. In the Product Listing page, user should be able to sort the products by predefined sort options.
5. In the Product Listing page, user should be able to sort the products by natural language.

Product Detail page:
1. User should be able to view the product details in the Product Detail page.
2. In the Product Detail page, user should be able to add the product to the cart.

Shopping Cart page:
1. User should be able to view the products in the Shopping Cart page.
2. In the Shopping Cart page, user should be able to remove the products from the cart.
3. In the Shopping Cart page, user should be able to update the quantity of the products in the cart.
4. In the Shopping Cart page, user should be able to checkout the products in the cart.

Checkout page:
1. User should be able to view the products in the Checkout page.
2. In the Checkout page, user should be able to complete the checkout.
